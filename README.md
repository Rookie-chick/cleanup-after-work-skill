# cleanup-after-work

一个 WorkBuddy 技能（Skill）：让 AI 在**每次完成工作后自动清理本轮会话产生的临时文件与中间垃圾**。

## 它解决什么问题

AI 干活时会留下一次性脚本、调试输出、被取代的中间稿。这个技能让 AI 在任务收尾时自动识别并清除这些"数字果皮"，同时**绝不碰用户文件和最终交付物**。

## 核心设计

**预防优于清理**——不让 AI 事后猜测什么是垃圾（不可靠且危险），而是约定：

- 干活时的一次性文件一律写入 `{工作区}/.workbuddy/tmp/`
- 收尾时直接清空该目录（目录内文件按定义全是 AI 临时品）
- 目录外的可疑文件列清单等用户确认，拿不准一律保留

判定铁律：只删「AI 创建的 + 本轮会话产生的 + 明确无用的」，三者缺一即保留。

## 安装

```bash
# 整个目录复制到 WorkBuddy 用户技能目录
cp -r cleanup-after-work ~/.workbuddy/skills/
```

## 触发方式

- 每次任务完成后自动收尾
- 或直接说："清理一下"、"删除临时文件"、"打扫"

## 文件结构

```
cleanup-after-work/
└── SKILL.md    # 技能定义（触发条件 + 判定清单 + 收尾流程 + 安全红线）
```
